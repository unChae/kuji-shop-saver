# Kuji Shop Saver

1kuji.com에서 선택한 매장을 저장하고 관리하는 크롬 확장 프로그램입니다. 매장별 메모를 정리하고, Google Maps에서 위치를 확인하거나 Google 마이맵용 CSV를 다운로드할 수 있습니다.

현재 버전: **0.4.0** · Manifest V3 · HTML / CSS / JavaScript

## 주요 기능

- 1kuji 페이지에서 선택한 매장의 이름, 주소, 매장 ID, 지도 링크 추출
- 길찾기 링크에 좌표가 포함되어 있으면 위도·경도 저장
- 사이드 패널에서 매장 저장 및 삭제
- 전화번호, 판매개시시간, 인당 구매 제한, 제한 수량, 메모 입력
- 드래그로 저장한 매장 순서 변경
- Google Maps에서 개별 매장 열기
- 저장한 매장 정보와 지도 링크를 클립보드에 복사
- 저장 목록을 Google 마이맵용 CSV로 다운로드
- 좌표가 있는 매장 2개 이상을 대상으로 Google Maps 방문 경로 생성

## 설치

1. 이 프로젝트를 다운로드하거나 Git으로 복제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
5. `manifest.json`이 들어 있는 프로젝트 폴더를 선택합니다.
6. 확장 프로그램 메뉴에서 **Kuji Shop Saver**를 고정하면 쉽게 접근할 수 있습니다.

별도의 패키지 설치, 빌드, 서버 실행은 필요하지 않습니다. Chrome의 사이드 패널을 지원하는 데스크톱 환경에서 사용합니다.

## 사용 방법

### 매장 저장

1. [1kuji](https://1kuji.com/)의 매장 검색 지도에서 매장을 선택합니다.
2. 확장 프로그램 아이콘을 클릭해 사이드 패널을 엽니다.
3. 현재 매장 이름과 주소를 확인한 뒤 **현재 매장 저장**을 누릅니다.

매장 이름과 주소가 모두 감지되어야 저장 버튼이 활성화됩니다. 중복 여부는 매장 ID가 있으면 ID로, 그렇지 않으면 이름과 주소로 판단합니다.

### 매장 정보 관리

- 저장한 매장의 **매장 정보 입력**을 펼쳐 부가 정보를 입력하고 **입력 저장**을 누릅니다.
- 매장 카드를 드래그해 목록 순서를 바꿉니다. 변경한 순서는 저장되며 CSV에도 반영됩니다.
- **구글맵 열기**로 매장 위치를 확인합니다.
- **삭제**로 목록에서 매장을 제거합니다.
- **전체 리스트 복사**로 저장된 정보를 한 번에 복사합니다. 아직 저장하지 않은 편집 내용은 포함되지 않습니다.

### Google 마이맵에 가져오기

1. 사이드 패널에서 **마이맵용 CSV 다운로드**를 클릭합니다.
2. `kuji-mymaps-YYYY-MM-DD.csv` 파일이 다운로드됩니다.
3. [Google 마이맵](https://www.google.com/maps/d/)에서 지도를 만들거나 엽니다.
4. 레이어의 **가져오기**를 클릭하고 CSV를 선택합니다.
5. 위치 열은 **Address**를 선택합니다. 모든 매장에 좌표가 있으면 **Latitude**와 **Longitude**를 선택할 수도 있습니다.
6. 마커 제목 열은 **Name**을 선택합니다.

CSV는 UTF-8로 생성되며 BOM을 포함하지 않습니다. 열 이름은 고유한 영문 알파벳으로 구성하고, 헤더에는 따옴표를 붙이지 않습니다. 데이터 셀에는 따옴표를 사용해 쉼표, 따옴표, 줄바꿈을 보존합니다.

| 열 | 내용 |
| --- | --- |
| Order | 저장 목록의 순서 |
| Name | 매장명 |
| Address | 주소 |
| Latitude | 위도, 없거나 유효하지 않으면 빈 값 |
| Longitude | 경도, 없거나 유효하지 않으면 빈 값 |
| Phone | 전화번호 |
| SaleStartTime | 판매개시시간 |
| PurchaseLimit | 인당 구매 제한: O / X / 빈 값 |
| LimitCount | 제한 수량 |
| Memo | 메모 |
| GoogleMapsUrl | Google Maps 검색 링크 |
| ShopId | 매장 ID |

마이맵의 공식 가져오기 안내는 [Google 도움말](https://support.google.com/mymaps/answer/3024836?hl=ko)을 참고하세요. 실제 마이맵 업로드 성공 여부는 별도 확인이 필요합니다.

### 방문 경로 보기

좌표가 있는 매장을 2개 이상 저장한 뒤 **최적 경로 보기**를 클릭합니다. 현재 위치를 요청하고 Google Maps 길찾기 페이지를 새 탭에서 엽니다.

현재 경로 기능에는 아래의 알려진 제한이 있으므로 생성된 방문 순서를 확인해 주세요.

## 저장 방식과 권한

저장 목록은 `chrome.storage.local`의 `shops` 배열에 보관됩니다. 별도의 서버나 계정 동기화는 없으며, 같은 브라우저 프로필에서 관리합니다. CSV 파일을 다시 확장 프로그램으로 가져오는 기능은 없습니다.

| 권한 | 용도 |
| --- | --- |
| storage | 매장 목록과 부가 정보 저장 |
| sidePanel | 사이드 패널 표시 |
| tabs | 활성 탭 확인 및 지도 탭 열기 |
| scripting | 현재 manifest에 선언되어 있으나 코드에서 직접 사용하지 않음 |
| https://1kuji.com/* | 해당 사이트에서 매장 정보 추출 |

## 프로젝트 구성

```text
manifest.json   확장 프로그램 설정 및 권한
content.js      1kuji 페이지의 매장 정보 추출과 변경 감지
background.js   탭별 현재 매장 정보 보관 및 메시지 중계
sidepanel.html  사이드 패널 화면과 스타일
sidepanel.js    저장, 편집, 정렬, 복사, CSV 다운로드, 경로 생성
```

페이지에서 추출한 매장 정보는 `CURRENT_SHOP` 메시지로 백그라운드에 전달됩니다. 백그라운드는 탭별 정보를 메모리에 보관하고 `CURRENT_SHOP_UPDATE` 메시지로 사이드 패널에 전달합니다. 사이드 패널은 `GET_CURRENT_SHOP` 메시지로 활성 탭의 정보를 요청합니다.

## 개발 및 문제 해결

코드를 수정한 뒤 `chrome://extensions`에서 확장 프로그램을 새로고침합니다. 1kuji 페이지도 새로고침하고 사이드 패널을 다시 열어 변경 내용을 확인합니다.

- **매장이 표시되지 않을 때:** 대상 주소가 `https://1kuji.com/`인지 확인하고 지도에서 매장을 다시 선택합니다. 사이트의 DOM 구조가 변경되면 `content.js`의 선택자를 수정해야 할 수 있습니다.
- **CSV 가져오기가 실패할 때:** 확장 프로그램을 새로고침한 뒤 CSV를 다시 다운로드합니다. 첫 행이 `Order,Name,Address,Latitude,Longitude,...`인지 확인하고 이전 파일과 구분합니다.
- **경로 버튼이 비활성화될 때:** 유효한 좌표가 저장된 매장이 2개 이상인지 확인합니다. 주소만 있는 매장은 경로 생성 대상에서 제외됩니다.

Node.js가 설치되어 있으면 JavaScript 문법을 확인할 수 있습니다.

```powershell
node --check content.js
node --check background.js
node --check sidepanel.js
```

## 알려진 제한

- 이미 저장한 매장을 **현재 매장 저장**으로 다시 저장하면 입력했던 전화번호, 판매 시간, 구매 제한, 메모가 초기화됩니다.
- 현재 경로 계산은 실제 도로 거리 대신 위도·경도 차이를 이용합니다. 순서 계산이 현재 위치가 아닌 `(0, 0)`에서 시작하고 첫 방문점을 최종 목적지로 지정하는 문제가 있어 최적 경로를 보장하지 않습니다.
- 백그라운드의 현재 매장 캐시는 메모리에만 있습니다. 서비스 워커가 재시작되면 페이지 새로고침이나 매장 재선택이 필요할 수 있습니다. 저장 목록은 별도로 로컬 저장소에 유지됩니다.
- 매장 정보 감지는 1kuji 페이지의 DOM과 길찾기 링크 형식에 의존합니다.
